# Gestion des tâches (Python)

Application console simple pour gérer des tâches quotidiennes.
Projet de binôme – Outils collaboratifs avec Git / GitHub, Licence 1.

## Fonctionnalités

- Ajouter une tâche (le titre vide est refusé)
- Afficher toutes les tâches avec leur numéro
- Rechercher une tâche par mot-clé
- Quitter le programme

## Étapes réalisées

1. Création du programme main.py (menu, ajout, affichage)
2. Rédaction du README.md
3. Ajout de la recherche de tâches
4. Publication sur GitHub puis mise à jour du projet

## Exécution

1. Ouvrir le dossier du projet dans VS Code.
2. Ouvrir main.py.
3. Cliquer sur le bouton *Run Python File* (triangle en haut à droite).
4. Suivre le menu dans le terminal.
